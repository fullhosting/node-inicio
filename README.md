# Ejemplo de Node.js para Full Hosting Cloud Apps

Una app mínima de Node.js, sin dependencias, lista para desplegar desde el asistente de Cloud Apps.

- Punto de entrada: `server.js`
- Comando de arranque: `npm start`
- Escucha en el puerto que define la plataforma (`PORT`) y en `0.0.0.0`
- `/health` responde `{"status":"ok"}`

Para usarlo como base de tu proyecto, creá tu propio repositorio a partir de este y desplegalo desde tu panel.
