Primeros pasos

Todo se hace desde el panel de Cloud Apps.

  1. 01

    Editá el código

    El punto de entrada es server.js. Creá tu propio repositorio a partir de este proyecto y cambiá lo que quieras.

  2. 02

    Publicá tus cambios

    Conectá tu repositorio de GitHub desde el panel y tu app se actualiza sola cada vez que subís un cambio.

  3. 03

    Cargá tus variables

    Las claves y configuraciones van en las variables de entorno de la app, nunca dentro del código.

  4. 04

    Usá tu propio dominio

    Agregá tu dominio desde el panel. El certificado HTTPS se instala y se renueva solo.
